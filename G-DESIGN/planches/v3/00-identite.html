Couleurs Psychoactive · nuit violette, aurores, reflets

Le violet est la matière (fond, verre des blocs), pas un accent. Un seul accent porte du sens : le vert aurore = chiffre validé par le ledger. Le corail = erreur, jamais en décor. Le magenta n'apparaît que dans la lumière (reflets, fumée).

Motif B · le bloc isométrique Baseten · volumes, texte imprimé sur les faces

Un seul volume, projeté à 30°, décliné en cinq rôles. La valeur est imprimée sur la face droite, le nom sur la face gauche, le glyphe sur le dessus. Arête claire + bande de reflet sur la face avant (lumière Psychoactive).

Sur chaque surface les motifs et leurs variantes

Ce sont les vraies images du Writeup (démo), en miniature.

Règles

  • Aurore pleine : une seule par surface (bannière ou module noyaux). Les figures prennent la bande.
  • Le vert aurore ne sert qu'aux chiffres validés ; une image sans chiffre validé n'en contient pas.
  • Lisibilité : une image de 1200 px affichée dans la colonne Kaggle (~760 px, largeur à vérifier) est réduite d'un tiers ; il faut donc ≥ 17 px de texte dans le fichier pour lire ≥ 11 px. Les figures V3 n'y sont pas encore (11–14 px) : à corriger à la déclinaison.
  • Les blocs iso portent des données (hauteur = valeur) ; jamais de bloc décoratif sans chiffre ni glyphe.
