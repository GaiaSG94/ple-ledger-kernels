ple-ledger-kernels

licenseApache-2.0writeupCC BY 4.0

The model never reads the drawing. An engineering agent harness for the PLE benchmark: the LLM only writes a typed spec; typed facts are extracted with provenance, deterministic kernels compute with unit checks, and every number in the deliverable is audited dimension by dimension.

Main finding (29 public dev tasks, demo values): dev-set score 0.11 → 0.31, tokens per task 62 k → 24 k.

Quick start

uv run python -m kit check
uv run python eval/run.py          # regenerates artifacts/ and the figures
uv run python -m kit artifacts

How it works

stagewhat it doestokens
EXTRACTdrawing + spec → typed facts with page and bbox0
SPECthe LLM writes a typed calculation that cites factsyes
SOLVEone of ≤ 12 deterministic kernels (pint / scipy)0
AUDITdimension network; violation → targeted re-emit; doubt → UNKNOWN0
PROVEre-measures produced geometry with a 2nd parser0
WRITEreport that can only cite ledger factssmall
